\section*{Purpose}

Test ice cover forcing by means of netCDF files.

%---------------------------------------------------------------------------------
\section*{Linked claims}
\phantom{text}\vspace*{-\baselineskip}
\begin{enumerate}
	\item Ice thickness and ice area fraction can be specified by means of netCDF files.
	\item Ice cover is properly taken into account in the pressure term.
	\item Ice cover map and history output is correct.
\end{enumerate}

%---------------------------------------------------------------------------------
\section*{Approach}
This test runs the same model as e02\_dflowfm / f020\_external\_forcing / c170\_icecover\_ascii\_cartesian and c172\_icecover\_ascii\_curvilinear with one difference: the data is provided by means of netCDF files.

%---------------------------------------------------------------------------------
\section*{Conclusion} 
The ice cover forcing as well as the ice map and history output work as intended.
The simulation results are consistent with the reference e02\_dflowfm / f020\_external\_forcing / c170\_icecover\_ascii\_cartesian.
